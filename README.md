Economics Research Website for Jordan
====================================

## Overview
A clean, organized website showcasing economics research tailored for students and general readers in Jordan. Built with a Python/Flask backend and a lightweight vanilla HTML/CSS/JS frontend.

## Source of Truth
- `content/economics-library.md` (~8,100 words, 4 categories, 6 sources, ~80 concept notes).

## Running Locally

1. **Prerequisites**: Ensure Python 3.10+ is installed (`py --version`).
2. **Install dependencies**:
   ```bash
   pip install -r backend/requirements.txt
   ```
3. **Start the backend server**:
   ```bash
   py -m backend.app
   ```
   *Note: Ensure you run the python module from the root repository directory.*
4. **Open in your browser**:
   Navigate to `http://localhost:5000`
